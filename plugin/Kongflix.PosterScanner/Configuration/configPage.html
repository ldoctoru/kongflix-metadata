Kongflix Poster Scanner

Scans movie and series libraries for items missing a poster (the series or movie entry itself — seasons and episodes are never checked) and forces Jellyfin's configured agents to refresh them. Run it manually or on a schedule from Dashboard → Scheduled Tasks → Scan for Missing Posters.

Libraries to scan

Unchecked libraries are skipped entirely. Music, home videos, box sets and book libraries are unchecked by default since they have no comparable "poster" concept.

Caps how many flagged items get refreshed in a single run, so a large backlog doesn't hammer your metadata providers. Anything left over is picked up on the next run. Use 0 for no limit.
